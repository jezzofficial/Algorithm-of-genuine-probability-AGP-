# Статус модификаций AGP

Выбранные для реализации идеи и их статус. Остальные идеи из первоначального
списка отброшены по решению автора — суть проекта в том, что результат
невоспроизводим и получается честным случайным выбором с перекосом бакетов.

---

## Реализовано

| Идея | Что сделано |
|---|---|
| ✅ A1 — ввод через аргументы командной строки | `python AGP.py Матрица Интерстеллар Начало` (argparse). Флаги `--count`, `--lang`, `--history`, `--no-history`. Флаг воспроизведения по сиду намеренно не добавлялся. |
| ✅ A7 — история результатов | Каждый розыгрыш дописывается строкой JSON в `history.jsonl`: timestamp, source, elements, seed, bucket_sizes, winner. Отключение — `--no-history`, свой путь — `--history`. |
| ✅ A8 — ввод из текстового файла | `python AGP.py --file варианты.txt` (по одному варианту на строку). |
| ✅ B13 — `secrets` вместо `random` | Веса бакетов, отбор чисел из бакетов и финальный выбор берутся из `secrets.SystemRandom` (случайность уровня ОС) в `agp_core.py`. |
| ✅ C15 — крайние случаи | Пустой список вариантов → сообщение и код выхода 1; `n = 0` и пустой ввод обрабатываются; Ctrl+C → «Прервано пользователем»; EOF (Ctrl+Z / Ctrl+D) заканчивает ввод; неверное количество → вопрос повторяется. |
| ✅ C16 — colorama необязательна | `try/except ImportError`: без colorama вывод без цвета, с colorama — как раньше. |
| ✅ C17 — валидация ввода | Пустые строки пропускаются с предупреждением; о повторяющихся вариантах выдаётся предупреждение (в интерактивных режимах — сразу при вводе). |
| ✅ C18 — локализация | `--lang ru|en` (по умолчанию ru): промпты, предупреждения и подписи переведены. |
| ✅ C19 — юнит-тесты | `tests/test_agp.py`, 22 теста: ядро, ввод, история, режимы CLI. Запуск: `python -m unittest discover -s tests` или `pytest tests`. |
| ✅ C20 — разбиение на модули | `agp_core.py` — чистая логика алгоритма; `agp_cli.py` — весь ввод-вывод; `AGP.py` и `AGP_zero.py` — тонкие точки входа без дублирования алгоритма. |

---

## Не реализуется (по решению автора)

- Воспроизводимость результата по сиду и детерминизм — противоречат сути проекта.
- Честный (равномерный) режим, веса вариантов от пользователя, несколько
  победителей, турниры, GUI/веб, статистика Монте-Карло и т.п.

---

## Примечания

- В режиме `--zero` (и в `AGP_zero.py`) элемент «0» — маркер завершения
  ввода, его нельзя использовать как вариант ответа. В остальных режимах
  «0» — обычный вариант.
- История по умолчанию пишется в `history.jsonl` в рабочей папке,
  откуда запущена программа.
