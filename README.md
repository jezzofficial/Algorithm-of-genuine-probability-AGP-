# The Algorithm of genuine probability (AGP)

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Linux%20%7C%20macOS%20%7C%20Windows-lightgrey.svg)]()

_Необычный генератор вероятностей: он не просто выбирает случайный вариант из списка,
а строит распределение через **перекос бакетов** — так, что разные варианты
выпадают с разной частотой, а результат каждый раз новый._

---

## **Суть**

Обычный `random.choice` даёт **ровно `1/N`** на каждый вариант.
Это честно, но предсказуемо: чем больше запусков, тем ближе частоты к равномерным
(закон больших чисел).

Этот проект **намеренно нарушает равномерность**. Алгоритм:

1. Генерирует случайный сид через `os.urandom` + `sha256`.
2. Строит 10 000 псевдослучайных чисел на основе сида.
3. Раскладывает числа по `N` бакетам, но **не по модулю**, а по **случайным весам** —
   каждый бакет получает свою долю интервала `[0, 1)`.
4. Из каждого бакета берёт случайное количество чисел.
5. Из получившегося пула выбирает финальное число, которое и определяет победителя.

Из-за разной ширины интервалов бакеты получаются **разного размера** —
например, `[7498, 2502]` или `[1200, 6800, 2000]`. Чем «тяжелее» бакет,
тем чаще выпадает его элемент.

## Запуск

```bash
python3 AGP.py
```

Пример работы:

~~~python
Сколько элементов?: 3
Элемент 1: Матрица
Элемент 2: Интерстеллар
Элемент 3: Начало
-----------
Сгенерированный сид: 91c0df067d31562dc448e3270db9b5cb...
Размеры бакетов: [4120, 4880, 1000]
-----------
Победитель: Интерстеллар
~~~

Каждый запуск — новый сид, новые размеры бакетов, новый победитель.
Даже при одинаковых элементах результат не повторяется.

## Как это работает

```
os.urandom(32)
    │
    ▼
sha256  ──►  seed_str
    │
    ▼
random.seed(seed_str)
    │
    ▼
10 000 чисел в [1, 10^6]
    │
    ▼
split_by_option_biased
    │  каждому бакету — свой вес
    │  числа раскладываются по интервалам [0, 1)
    ▼
N бакетов разного размера
    │
    ▼
случайный take из каждого бакета
    │
    ▼
pool пар (число, индекс бакета)
    │
    ▼
random.choice(pool)  ──►  elements[idx]
```

### Ключевые функции

| Функция | Назначение |
|---|---|
| `generate_seed()` | 32 случайных байта из `os.urandom`, прогнанные через `sha256` |
| `build_numbers(seed, count)` | 10 000 псевдослучайных чисел на основе сида |
| `split_by_option_biased(numbers, n)` | Раскладка чисел по `n` бакетам с разными весами |
| `pick(elements)` | Полный цикл: сид → числа → бакеты → победитель |
| `main()` | Ввод элементов, запуск, вывод результата |
