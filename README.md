# The Algorithm of genuine probability (AGP)

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Linux%20%7C%20macOS%20%7C%20Windows-lightgrey.svg)]()

_Необычный генератор вероятностей: он не просто выбирает случайный вариант из списка,
а строит распределение через **перекос бакетов** — так, что разные варианты
выпадают с разной частотой, а результат каждый раз новый._

---

## **Суть**

Обычный `random.choice` даёт **ровно `1/N`** на каждый вариант.
Это честно, но предсказуемо: чем больше запусков, тем ближе частоты к равномерным
(закон больших чисел).

Этот проект **намеренно нарушает равномерность**. Алгоритм:

1. Генерирует случайный сид через `os.urandom` + `sha256`.
2. Строит 10 000 псевдослучайных чисел на основе сида.
3. Раскладывает числа по `N` бакетам, но **не по модулю**, а по **случайным весам** —
   каждый бакет получает свою долю интервала `[0, 1)`.
4. Из каждого бакета берёт случайное количество чисел.
5. Из получившегося пула выбирает финальное число, которое и определяет победителя.

Из-за разной ширины интервалов бакеты получаются **разного размера** —
например, `[7498, 2502]` или `[1200, 6800, 2000]`. Чем «тяжелее» бакет,
тем чаще выпадает его элемент.

Результат **принципиально невоспроизводим**: сид каждый раз новый, а веса
бакетов, отбор чисел и финальный выбор берутся из `secrets.SystemRandom` —
источника случайности уровня операционной системы.

## Запуск

### Классический режим (количество + элементы)

```bash
python3 AGP.py
```

```python
Сколько элементов? (int): 3
Элемент 1: Матрица
Элемент 2: Интерстеллар
Элемент 3: Начало
-----------
Сгенерированный сид: 91c0df067d31562dc448e3270db9b5cb...
Размеры бакетов: [4120, 4880, 1000]
-----------
Победитель: Интерстеллар
```

### Аргументы командной строки

```bash
python3 AGP.py Матрица Интерстеллар Начало
```

### Варианты из файла

```bash
python3 AGP.py --file варианты.txt
```
_Файл — обычный текст, по одному варианту на строку._

### Ввод до символа 0

```bash
python3 AGP.py --zero
# или
python3 AGP_zero.py
```

```python
Вводите элементы по одному. Введите 0, чтобы закончить.
Элемент 1 (0 — завершить): Матрица
Элемент 2 (0 — завершить): Интерстеллар
Элемент 3 (0 — завершить): Начало
Элемент 4 (0 — завершить): 0
```

Элемент `0` в этом режиме — маркер завершения ввода, поэтому его нельзя
использовать как вариант ответа. В остальных режимах `0` — обычный вариант.

### Флаги

| Флаг | Назначение |
|---|---|
| `--file PATH`, `-f` | читать варианты из текстового файла |
| `--zero` | интерактивный ввод до символа 0 |
| `--count N` | сколько чисел строить на основе сида (по умолчанию 10000) |
| `--lang ru\|en`, `-l` | язык интерфейса |
| `--history PATH` | файл истории (по умолчанию `history.jsonl`) |
| `--no-history` | не сохранять результат в историю |

## Как это работает

```
os.urandom(32)
    │
    ▼
sha256  ──►  seed_str
    │
    ▼
random.seed(seed_str)
    │
    ▼
10 000 чисел в [1, 10^6]
    │
    ▼
split_by_option_biased
    │  каждому бакету — свой вес (secrets.SystemRandom)
    │  числа раскладываются по интервалам [0, 1)
    ▼
N бакетов разного размера
    │
    ▼
случайный take из каждого бакета (secrets.SystemRandom)
    │
    ▼
pool пар (число, индекс бакета)
    │
    ▼
secrets.SystemRandom.choice(pool)  ──►  elements[idx]
```

### Ключевые функции

| Функция | Файл | Назначение |
|---|---|---|
| `generate_seed()` | `agp_core.py` | 32 случайных байта из `os.urandom`, прогнанные через `sha256` |
| `build_numbers(seed, count)` | `agp_core.py` | `count` псевдослучайных чисел на основе сида |
| `split_by_option_biased(numbers, n)` | `agp_core.py` | Раскладка чисел по `n` бакетам со случайными весами |
| `pick(elements, count)` | `agp_core.py` | Полный цикл: сид → числа → бакеты → победитель |
| `main(argv)` | `agp_cli.py` | Разбор аргументов, выбор способа ввода, вывод, история |
| `read_until_zero()` | `agp_cli.py` | Интерактивный ввод до символа 0 |
| `read_by_count()` | `agp_cli.py` | Интерактивный ввод с указанием количества |
| `append_history(path, record)` | `agp_cli.py` | Запись строки JSON в файл истории |
| `duplicates_of(elements)` | `agp_cli.py` | Поиск повторяющихся вариантов для предупреждений |
